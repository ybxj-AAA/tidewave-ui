Licence questions

Before you buy

Can I use this for client work?

That's your call to make and to state clearly, because the licence in this repo is a template too. The structure supports a per-project tier and an unlimited tier; what you publish should match what you're willing to enforce.

Can I resell or redistribute it?

The sample licence says no. That's the usual shape for a UI kit: you buy it to build products, not to repackage and resell. If you change the terms, change the LICENSE file so buyers aren't guessing.

What about refunds?

The refund policy on this template is a placeholder. Whatever you publish, honour it — a stated refund window is the cheapest trust signal a small seller has.

Do I need to know CSS to use it?

Not really. The templates are plain HTML you edit by swapping text and sections. Customizing colours is a five-line token override. If you want to change layout, some CSS helps.

What if I need a React version?

There isn't one. The markup is plain HTML with class names, so it converts to JSX by hand — no framework-specific syntax to untangle — but no port is included in any tier.
