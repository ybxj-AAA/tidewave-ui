License questions

Before you buy

Can I use this for client work?

Yes on Pro and Team. Pro covers unlimited projects by a single designer or developer, including client work. Team covers a shared studio of up to ten seats.

Can I resell or redistribute it?

No. The license covers using Tidewave to build end products. Reselling the kit itself, or distributing it as part of a template or component library, is not permitted.

Is there a refund policy?

Thirty days, no questions asked. Email the address on your receipt and the refund goes back the same way it came.

Do I need to know CSS to use it?

Not really. The templates are plain HTML you edit by swapping text and sections. Customizing colors is a five-line token override. If you want to change layout, some CSS helps.

What if I need a React version?

Ports for React and Vue are included in the Team plan. The Pro plan is HTML/CSS; the markup translates to JSX with little friction since there's no framework-specific syntax.

Every page you just clicked through is included in the Pro plan. No watermarks, no feature gates on the demo.
