Theming

Components consume semantic tokens only. To rebrand the kit, override the aliases in tokens.css; no component file requires changes.

/* override the whole kit with 5 lines */
:root {
  --tw-brand:      #e8590c;  /* any hue */
  --tw-brand-hover:#c94a08;
  --tw-radius-lg:  4px;     /* sharper corners */
  --tw-font-sans:  "IBM Plex Sans", sans-serif;
  --tw-container:  1320px;
}
