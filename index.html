Theming

To rebrand, override the aliases in tokens.css. No component file needs to change.

/* override the whole kit with five lines */
:root {
  --tw-brand:      #0f766e;  /* any hue */
  --tw-brand-hover:#115e59;
  --tw-radius-lg:  6px;     /* sharper corners */
  --tw-font-sans:  "IBM Plex Sans", sans-serif;
  --tw-container:  1240px;
}

That's the whole library.

Eighteen components, eight CSS files, five page samples and a validator. No build step, no dependencies, no watermark on anything.
